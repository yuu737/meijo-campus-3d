# R158の照明と表示

建物・外構63区画に、保存モデルと同じSHA-256で生成した昼光を適用する。表面の繰り返し材質UVと照明UVを分離し、照明アトラスの解像度を保持する。KTX2テクスチャ・ミップマップとMeshopt形状を使用する。

樹木169本は元の近景形状・幹と葉の材質を保ち、PBR照明と中・遠景LODを使用する。初期表示は標準画質、樹木ON。移動メニューと表示設定で樹木を切り替えられる。計算済み昼光と太陽光の影も表示設定から切り替えられる。

BlenderのAgX Medium High Contrastに対応したコントラスト変換を使用する。Three.jsとCyclesの最終画像が同一という意味ではない。標準・精細は同じ光と材質を用い、主に解像度と輪郭処理を変更する。

内装のWeb表示は無効。LODや表示中の区画に関係なく、歩行は専用の衝突形状を参照する。モデルと衝突・昼光データの一致をビルド時に検査する。
